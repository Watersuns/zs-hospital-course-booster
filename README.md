# 中山医院网课助手

针对 **https://elearning.zs-hospital.sh.cn** 网课平台的 [Tampermonkey](https://www.tampermonkey.net/)（油猴）用户脚本。

解决看网课时常见的几个限制：切到后台就弹窗暂停、不能倍速、不能拖进度条，以及因学习时长统计导致课程无法完成的问题。

> 仅供个人学习与前端技术研究使用，请遵守平台相关规定，使用风险自负。

## 功能

| 功能 | 说明 |
|------|------|
| 后台播放 | 切后台 / 切标签页不再弹窗、不暂停，视频继续播放 |
| 倍速播放 | 播放器没有倍速选项时，用悬浮面板自由切换 1.0x ～ 3.0x |
| 拖动进度 | 绕过「拖动后弹回」的限制，用面板进度条自由跳转 |
| 快速跳转 | 「答题」跳到视频 3/5 处 此时可答题，「评分」跳到结尾前 5 秒 方便评分|
| 一键补完 | 自动按服务器要求的「达标时长」补齐学习记录，标记该视频已完成 |

## 安装

1. 给浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge 等 Chromium 内核浏览器均可）。
2. 打开 Tampermonkey 管理面板 → 「新建脚本」。
3. 将本仓库 [`zs-hospital-course-booster.user.js`](zs-hospital-course-booster.user.js) 的完整内容粘贴进去，保存（`Ctrl/Cmd + S`）。
4. 打开网课视频页面并刷新，右下角会出现「网课助手」悬浮面板。

## 使用

- **倍速**：点击面板上的 `1.0x` / `1.5x` / `2.0x` … 按钮。
- **进度**：拖动面板里的「进度」滑条。
- **跳转**：点击「答题」或「评分」完成中间段的题目和评分。
- **补完**：点击「一键补完」，弹窗显示「已完成 ✅」即表示该视频达标。
- **建议流程**：进入视频点击「答题」按钮，完成答题，再点击「评分」按钮完成评分，点击「一键补完」，弹窗显示「已完成 ✅」等待几秒时间结束，提示本课程已完成。
- **特别提醒**：如提示“您的视频课件观看时长未达到，请继续观看以完成学习“可刷新网页重试

> 系列课程由多段视频组成、每段独立结算时，需要在**每个视频页面各点一次「一键补完」**。
